# Locations Library

Reusable **environment set-pieces**. Each file describes a place in both of its
layers — the **Physical** world of matter and the **Echo Field** aspect weighted by
*significance, not mass* (`lore/echo-field.md`) — plus the significance that gives
the Echo layer its shape.

These are **environment-only**. No characters are placed and no timeline is assigned
here; that happens later, when `scene-builder` sets a scene *in* one of these places
and pulls the cast and time from the continuity system. Think of this as the set,
built and lit before the actors arrive.

Each location also lists **story hooks** — the characters and threads it connects to
— so a scene can be dropped in without re-deriving what the place is *for*. Summary
rows live in `continuity/world-state.md`.
