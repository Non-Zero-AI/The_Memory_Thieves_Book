# Plot

The story's structure, from the whole series down to each book.

| File | Scope |
|------|-------|
| `series-arc.md` | The master spine — throughline, the deep truth (author-facing), reveal distribution, and the open/closed ending decision |
| `core-premise.md` | The premise and moral engine |
| `reveal-layers.md` | The eight-layer reveal ladder |
| `misdirection.md` | The twist/misdirection strategy — skillfully, not overly |
| `book-1.md` … `book-5.md` | Per-book plot: logline, main plot, act structure & key scenes, twists, threads advanced |

**Reading order for the spine:** `series-arc.md` → `misdirection.md` → the book files
in order.

**Author-facing.** These files hold spoilers and the bottom of the mystery. What a
character or the manuscript may know at any point is governed by knowledge-gating in
`continuity/`, not by what's written here.

**Next grain down:** once a book's plot is set, `chapter-builder` turns a stretch of it
into a chapter of beats, and `scene-builder` turns each beat into a scene — each
checking the reveal ladder and the gates as it goes.
