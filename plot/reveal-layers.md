# Reveal Layers

The eight-layer ladder of the mystery. How the layers distribute across the books, the
truth they bottom out into, and how each turn is handled are in `plot/series-arc.md`
and `plot/misdirection.md`.

## Layer 1: Memory Has a Place

Human memory has a physical-world component and an Echo Field component.

This discovery begins as neuroscience, becomes espionage, and eventually becomes metaphysics.

## Layer 2: The Archivists Are Villains

The public believes the Archivists are memory thieves and identity criminals.

They appear to be the greatest threat on Earth.

## Layer 3: The Archivists Are Containment Agents

The Archivists erase and steal memories to prevent dangerous memory structures from forming or spreading.

Their crimes are real, but their motive is containment.

## Layer 4: Memories Become Entities

Powerful memories, especially those shaped by trauma, grief, worship, obsession, fear, or mass belief, can become persistent structures in the Echo Field.

Some structures become intelligent.

## Layer 5: The Curators Are Not Evil

The Curators oppose the Archivists because they believe memory transcendence can save humanity.

They want to merge humanity with Echo Field entities to end death, preserve knowledge, and create a collective civilization.

They can make a beautiful argument.

That is what makes them dangerous.

## Layer 6: Both Factions Are Being Manipulated

The Archivists believe suppression will save humanity.

The Curators believe merger will save humanity.

Both are acting inside a game neither fully understands.

## Layer 7: The Ancient Predator

Every intelligent civilization eventually discovers memory manipulation.

Every civilization creates dense collective memory.

Every civilization eventually becomes food.

The entity beneath the Echo Field feeds on civilizations once they reach sufficient memory density.

## Layer 8: The Firstborn Witness

Elias Voss carries a hidden memory from the Firstborn: a memory of the Silence, the event that ended the oldest known Echo-connected civilization.

This memory may prove what the real threat is.

It may also prove that everyone has misunderstood it.
