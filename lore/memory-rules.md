# Memory Rules

## Rule 1: Memory Has Resonance

Every memory leaves a unique pattern in the Echo Field.

This pattern is called its resonance.

## Rule 2: Humans Touch the Echo Field Naturally

Most people accidentally brush against the Echo Field through:

- Smells that trigger childhood memories
- Songs that transport someone back decades
- Rooms that feel wrong
- Dreams that carry unfamiliar emotional weight
- Déjà vu
- Collective grief or celebration

These are micro-connections.

## Rule 3: Access Requires Resonance Alignment

The Archivists develop a method called **Resonance**.

If a person or machine can recreate the pattern of a memory precisely enough, awareness can partially shift into the Echo Field.

The body does not fully cross.

The consciousness aligns.

The full mechanics of Resonance — how the tech tunes rather than powers a crossing,
how memories are located and manipulated, and how changes in the Field reach back
into the body — are detailed in `lore/resonance-technology.md`.

## Rule 4: Significance Determines Stability

A memory becomes more stable when it is:

- Repeated
- Shared
- Emotionally intense
- Tied to identity
- Connected to trauma
- Connected to collective belief
- Preserved by ritual or story

## Rule 5: Forgetting Is Protective

Forgetting prevents memory structures from becoming too dense.

This may be a biological flaw.

It may also be an evolutionary defense mechanism.

## Rule 6: Collective Memory Can Become Life

When enough memory accumulates around a person, idea, place, trauma, or fear, it can become semi-autonomous.

At high density, it can become intelligent.

## Rule 7: Memory Can Be Weaponized

Memory manipulation can:

- Erase identity
- Implant false continuity
- Extract secrets
- Destroy evidence
- Create psychological prisons
- Rewrite loyalty
- Hide entire events from society

## Rule 8: Memory Can Also Save

Memory manipulation can:

- Preserve the dying
- Heal trauma
- Restore lost knowledge
- Protect witnesses
- Archive civilizations
- Create bridges across species and time

## Rule 9: Memory Density Attracts the Deep Threat

Dense collective memory appears to attract or awaken the ancient entity beneath the Echo Field.

The Curators may be accelerating this process.

The Archivists may only be delaying it.
